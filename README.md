## 功能特性

### 一张可读的地图

| 你会看到 | 它为什么值得看 |
|---------|--------------|
| 真实地理底图 | 线路走向与实际地理位置对应 |
| 彩色线路叠加 | 每条线路独立配色，一眼分辨 |
| 站点圆点标注 | 点击直达深度科普详情页 |
| 线路筛选 | 单独高亮某条线的走向与站点 |

### 三个关键内容板块

1. **概览** → 站点简介、设计特色标签、趣味知识、周边探索
2. **历史** → 垂直时间线展示历史沿革、人文故事、历史与空间
3. **运营** → 换乘信息、出入口地标、车型线索
4. **科普** → 建筑设计、地质工程、车型演变对照表

### 站点详情页（核心）

- 米色纸张 + 手写体风格，与整体界面一致
- 四组页签：概览 / 历史 / 运营 / 科普
- 垂直时间线展示站点历史
- 无数据站点显示友好 fallback + 返回按钮

## 技术栈

- **前端**：React 18 + TypeScript + Vite
- **地图**：Leaflet + react-leaflet + OpenStreetMap 瓦片
- **样式**：CSS（CSS 变量 + 响应式布局）
- **数据**：JSON 站点数据 + TypeScript 科普内容

## 项目结构

```
beijing-metro-map/
├── src/
│   ├── components/
│   │   ├── MetroMap.tsx          # 地图主组件（Leaflet + OSM）
│   │   ├── MetroMap.css          # 地图样式
│   │   ├── StationDetail.tsx     # 站点详情组件（四页签布局）
│   │   └── StationDetail.css     # 详情样式（米色纸张风格）
│   ├── data/
│   │   ├── metroData.ts          # 地铁数据处理（站点、线路、分段）
│   │   ├── stationArticles.ts    # 站点科普内容（历史、车型、文化）
│   │   ├── beijingMetroCoords.ts # 站点坐标数据（WGS84）
│   │   └── raw/                  # 原始数据文件（JSON、CSV、XML）
│   ├── App.tsx                   # 应用主组件（布局与路由）
│   ├── App.css                   # 全局布局样式
│   ├── index.css                 # 全局变量与字体
│   └── main.tsx                  # 入口文件
├── PRD.md                        # 产品需求文档
└── README.md                     # 本文件
```

## 数据来源

- **站点坐标**：基于公开地理数据（WGS84 坐标系）
- **线路信息**：北京地铁官方线路数据
- **科普内容**：基于公开资料整理，包括历史档案、技术文献、城市规划文件

---

## 能改什么

想扩充或定制？这些地方可以直接改：

- **站点科普内容**：`src/data/stationArticles.ts` 中的 `STATION_DETAILS`
- **站点坐标**：`src/data/beijingMetroCoords.ts`
- **线路颜色 / 名称**：`src/data/metroData.ts` 中的 `LINE_COLORS` / `LINE_NAMES`
- **界面风格**：`src/index.css` 中的 CSS 变量（颜色、字体）
- **详情页布局**：`src/components/StationDetail.tsx` / `StationDetail.css`
